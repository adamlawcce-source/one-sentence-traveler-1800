A tiny Node 22 program for the make.fun bounty
[One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

`main.ts` writes one sentence to `/output/entry.txt`: an explanation of the
modern internet for someone who has just stepped out of the year 1800,
built only from things they already know — a library, a post office, a
market, a road — with no word coined after their time. No network, no
randomness, no input — the same sentence on every run.

Run it with Node 22:

```sh
node main.ts
```
